# คู่มือติดตั้งระบบลงทะเบียน IT Open House

ระบบนี้ประกอบด้วย 3 ส่วน:
- `index.html` — ฟอร์มลงทะเบียนสำหรับนักเรียน (เปิดสาธารณะ)
- `dashboard.html` — หน้า Dashboard สำหรับทีมงาน (ต้องใส่รหัสผ่าน)
- `Code.gs` — โค้ด backend ที่รันบน Google Apps Script ทำหน้าที่อ่าน/เขียนข้อมูลใน Google Sheets

ไม่ต้องมี server แยก ใช้ Google Sheets + Google Apps Script เป็น backend ทั้งหมด ฟรี

---

## ขั้นตอนที่ 1: สร้าง Google Sheet

1. ไปที่ [sheets.google.com](https://sheets.google.com) สร้างสเปรดชีตใหม่ ตั้งชื่อเช่น `IT Open House - ข้อมูลลงทะเบียน`
2. ไม่ต้องสร้างชีตหรือหัวตารางเอง — โค้ดจะสร้างชีตชื่อ `Students` พร้อมหัวตารางให้อัตโนมัติในการรันครั้งแรก

## ขั้นตอนที่ 2: ใส่โค้ด Apps Script

1. ในสเปรดชีตที่สร้างไว้ ไปที่เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ออกทั้งหมด แล้วคัดลอกเนื้อหาจากไฟล์ `Code.gs` ที่แนบมาไปวางแทน
3. แก้บรรทัดนี้ให้เป็นรหัสผ่านที่ต้องการ (ใช้สำหรับ login เข้า Dashboard):
   ```js
   const ADMIN_PASSWORD = 'เปลี่ยนรหัสผ่านนี้ก่อนใช้งานจริง';
   ```
4. กด **บันทึก** (ไอคอนแผ่นดิสก์ หรือ Ctrl+S)

## ขั้นตอนที่ 3: Deploy เป็น Web App

1. มุมขวาบนกด **Deploy → New deployment**
2. คลิกไอคอนเฟือง เลือกประเภทเป็น **Web app**
3. ตั้งค่า:
   - **Execute as**: `Me` (บัญชีของคุณ)
   - **Who has access**: `Anyone` (จำเป็น เพื่อให้นักเรียนที่ไม่ได้ login ส่งฟอร์มได้)
4. กด **Deploy**
5. ระบบจะขอ **Authorize access** — เลือกบัญชี Google ของคุณ แล้วกด "Advanced" → "Go to (ชื่อโปรเจกต์) (unsafe)" → Allow (ขึ้นเตือนเพราะเป็นสคริปต์ของคุณเอง ไม่ใช่ของบุคคลที่สาม ปลอดภัย)
6. คัดลอก **Web app URL** ที่ได้ (จะขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

> ⚠️ ทุกครั้งที่แก้โค้ดใน `Code.gs` ต้องกด **Deploy → Manage deployments → แก้ไข (ไอคอนดินสอ) → New version → Deploy** ใหม่ ไม่งั้น URL เดิมจะยังใช้โค้ดเวอร์ชันเก่า

## ขั้นตอนที่ 4: เชื่อม URL เข้ากับหน้าเว็บ

เปิดไฟล์ทั้ง 2 ไฟล์ (`index.html` และ `dashboard.html`) ค้นหาบรรทัด:

```js
const APPS_SCRIPT_URL = "https://script.google.com/macros/s/XXXXXXXXXXXXXXXXXXXXXXXX/exec";
```

แล้วแทนที่ด้วย Web app URL ที่ได้จากขั้นตอนที่ 3 (URL เดียวกันทั้งสองไฟล์)

## ขั้นตอนที่ 5: นำไฟล์ HTML ไปโฮสต์

เลือกวิธีใดวิธีหนึ่ง:
- **ง่ายที่สุด**: อัปโหลดไฟล์ขึ้น GitHub Pages / Netlify Drop / Vercel (ลาก-วางได้เลย ฟรี)
- **เปิดจากเครื่อง**: ดับเบิลคลิกไฟล์ `index.html` เปิดในเบราว์เซอร์ได้ทันที (เหมาะกับทดสอบ ไม่เหมาะกับใช้จริงในงาน เพราะต้องแชร์ลิงก์ให้นักเรียนสแกน)

แนะนำใช้ **Netlify Drop** (netlify.com/drop) — ลากโฟลเดอร์ที่มีไฟล์ HTML ทั้งหมดไปวาง จะได้ลิงก์สาธารณะทันทีโดยไม่ต้องสมัครสมาชิก

## ขั้นตอนที่ 6: ทดสอบก่อนใช้งานจริง

1. เปิด `index.html` → กรอกฟอร์มทดสอบ → กดส่ง
2. เปิด Google Sheet ดูว่าข้อมูลเข้าไปในชีต `Students` หรือไม่
3. เปิด `dashboard.html` → ใส่รหัสผ่านที่ตั้งไว้ → ตรวจว่ากราฟและตารางแสดงข้อมูลถูกต้อง
4. ทดสอบปุ่ม **ส่งออก CSV** ว่าเปิดใน Excel แล้วภาษาไทยไม่เพี้ยน

## หมายเหตุด้านความปลอดภัย

- รหัสผ่าน Dashboard ถูกส่งผ่าน URL (query string) ซึ่งเพียงพอสำหรับงานอีเวนต์ระยะสั้นที่มีความเสี่ยงต่ำ แต่**ไม่เหมาะกับข้อมูลที่ต้องการความปลอดภัยสูง** หากต้องการความปลอดภัยมากขึ้นในอนาคต แนะนำย้ายไปใช้ Supabase หรือ Firebase ที่มีระบบ Authentication จริง
- อย่าแชร์ลิงก์ Google Sheet หรือ Apps Script editor ให้บุคคลภายนอก มีเพียงลิงก์ Web App (`/exec`) เท่านั้นที่ควรเผยแพร่ (สำหรับฟอร์ม) และไม่ควรเผยแพร่รหัสผ่าน Dashboard นอกทีมงาน
- ควรลบ/ย้ายข้อมูลออกจาก Google Sheet หลังจบงานตามระยะเวลาที่แจ้งไว้ในข้อความยินยอม PDPA ในฟอร์ม

## การปรับแต่งเพิ่มเติม

- เปลี่ยนสีธีมหรือชื่อคณะ: แก้ตัวแปร CSS (`:root`) ด้านบนของแต่ละไฟล์ HTML
- เพิ่มสาขาวิชา: แก้ทั้ง `index.html` (ตัวเลือกในฟอร์ม + SVG), `dashboard.html` (`MAJOR_COLORS`) ให้ตรงกัน
- เพิ่มฟิลด์ข้อมูล: เพิ่มใน `index.html` (input), `Code.gs` (HEADERS + REQUIRED_FIELDS + appendRow), และ `dashboard.html` (ตาราง) พร้อมกันทั้ง 3 จุด
